## 📌 Tentang BeOne

BeOne adalah brand penyedia layanan pembuatan website dan solusi digital kustom. Berfokus pada kemudahan akses bagi pelanggan pertama, BeOne menawarkan paket website portofolio terjangkau (mulai Rp150.000) untuk membantu:
- **Web Developer & Programmer**: Memamerkan live demo proyek web dan keahlian teknis.
- **UI/UX & Graphic Designer**: Menampilkan showcase visual karya, studi kasus, dan tools desain.
- **Freelancer & Kreator**: Membangun personal branding yang kredibel dan memudahkan klien menghubungi langsung.
- **Mahasiswa & Fresh Graduate**: Memiliki resume interaktif modern untuk memikat recruiter.
- **Pelaku Usaha & Bisnis**: Membangun landing page, company profile, e-commerce, hingga web app kustom.

## 🛡️ Kebijakan Garansi Bug 30 Hari & Maintenance

1. **Cakupan Garansi Bug 30 Hari**:
   - Menjamin perbaikan error fungsional, broken layout di berbagai layar browser/mobile, atau malfungsi fitur bawaan yang dibangun BeOne sesuai spesifikasi kesepakatan awal tanpa biaya tambahan.
   - **Eksklusi Garansi**: Tidak mencakup penambahan fitur baru, perombakan desain di luar kesepakatan, gangguan server/registrar pihak ketiga, atau kerusakan akibat modifikasi kode oleh pihak lain.
2. **Transparansi Biaya Domain & Hosting Pihak Ketiga**:
   - Untuk paket yang menggunakan hosting gratis (Vercel, Netlify, GitHub Pages), tidak ada biaya sewa server bulanan atau tahunan.
   - Untuk website dengan nama domain berbayar (.com/.id) atau server cloud berbayar, biaya perpanjangan tahunan dibayarkan secara riil dan transparan sesuai tagihan resmi registrar/provider pihak ketiga tanpa markup tersembunyi.
3. **Paket Maintenance Tahunan**:
   - Berfokus pada pemeliharaan teknis berkala: monitoring uptime, asistensi pembaruan SSL/HTTPS, pemeriksaan keamanan dependensi, serta perbaikan kendala ringan. Kami tidak menjanjikan fitur infrastruktur atau backup otomatis yang tidak terkonfigurasi.

## 🚀 Panduan Menjalankan Proyek Lokal

### Persyaratan Sistem
- Node.js versi 18.18 atau lebih baru (direkomendasikan Node.js LTS v20+)
- Package manager: `npm`, `yarn`, `pnpm`, atau `bun`

### Langkah Instalasi

1. **Clone repository:**
   ```bash
   git clone https://github.com/Albaihaqi354/beone.git
   cd beone
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. Buka peramban di [http://localhost:3000](http://localhost:3000).

## 🌐 Deployment

Proyek ini telah dikonfigurasi untuk deployment instan di platform **Vercel**:
1. Hubungkan repository GitHub `Albaihaqi354/beone` ke akun Vercel.
2. Vercel secara otomatis mendeteksi framework **Next.js**.
3. Build command: `npm run build`
4. Output directory: `.next`

Setiap push ke branch utama (`main`) akan memicu deployment otomatis ke URL produksi [https://beone-here.vercel.app](https://beone-here.vercel.app).
